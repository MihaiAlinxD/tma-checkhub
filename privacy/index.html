Informații despre datele asociate utilizării site-ului TMA CheckHub.

Ce funcționează acum

Site-ul este găzduit pe GitHub Pages. Furnizorul de găzduire poate prelucra date tehnice de acces conform propriilor politici.

Preferința de limbă

Site-ul salvează local în browser limba selectată pentru a o păstra între vizite. Această preferință nu este transmisă de site către un server propriu.

Formulare și conturi

În prezent, site-ul nu are un formular de contact funcțional și nu permite crearea de conturi pe site. Politica va fi actualizată înainte de activarea unor asemenea servicii.

Document în pregătire

Aceasta este o prezentare preliminară, care necesită completare și verificare înainte de lansarea oficială.
